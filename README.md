# 🍔 Bill Burger Challenge

A Java OOP project that simulates a burger meal ordering system.

## Features
- Create burger meals
- Add toppings
- Calculate total price
- Print order details

## OOP Concepts Used

- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding

## Technologies

- Java
- NetBeans
- Git
- GitHub
